# 09. ライセンスと帰属

## upstream

`dhq-boiler/Unofficial-VS-MCP`

このプロジェクトのソースをForkして使用する場合、
upstreamに含まれるMIT Licenseの条件を守る。

特に:
- upstreamの著作権表示を保持する
- upstreamのMIT License本文を保持する
- LICENSEファイルを不用意に削除・置換しない

## Extended側

Extended独自コードの著作権・ライセンスを追加する場合でも、
upstream由来コードに適用される既存の著作権表示とMIT Licenseを消さない。

READMEには少なくとも以下の関係を明示することを推奨する。

```text
Unofficial-VS-MCP-Extended is a fork of
dhq-boiler/Unofficial-VS-MCP and is maintained with upstream synchronization.
```

この文書は法的助言ではなく、開発運用上の整理である。
最終的には実際のupstream LICENSEを基準にする。
